🛠 Runtime Extraction Architecture

King's Valley II operates under a strict 100% clean-room pipeline. The repository contains only pure C# source code, open-source tools, and vector/UI definitions. On first boot, the player's own cartridge images are analyzed and decoded into the user's application directory (%APPDATA%\KingsValley\extracted\).

⚖ MSX1 (RC-760) vs MSX2 (RC-761) Dual-Architecture

MSX1 Flavor (RC-760)

  • Video Mode: TMS9918A SCREEN 2 (256×192, 1:1 square pixels).
  • Letterboxing: Perfectly centered vertically with 10 px top/bottom black borders within the 256×212 design frame.
  • Palette: 16 fixed hardware TMS colors.
  • Backgrounds: 184 full-room VRAM dumps (sNN_rMM.bin, 24,614 bytes each), decoded byte-for-byte with items and soulstones dynamically separated.
  • Sprites: 1bpp pattern table composite with hardware sprite layering.

MSX2 Flavor (RC-761)

  • Video Mode: Yamaha V9938 Screen 5 (256×212, full height).
  • Color Depth: 16 programmable colors from a 512-color RGB palette.
  • Dynamic Animation: Real-time Color 6 palette cycling for water and torches.
  • Background Assembly: Built at runtime via RoomAssembler from 4bpp tileblocks (blocks_p1..6.bin), murals (murals.json), and decorations (decorations.json).
  • Sprites: 16-color direct RLE decompressed poses with hardware color compositing.
