# King's Valley II v1.0.0

A fresh source baseline with standalone cartridge extraction and updated gameplay.

- Separate validated MSX1 and MSX2 graphics/audio collections and automatic English HTML reports.
- Native runtime screen/room assembly, improved sprite extraction, intro playback and door animation.
- Correct music introductions, projectile collision across rooms and triggered falling walls.
- Optional MSX1 object backgrounds: Original or Transparent.

The archives contain the application and open-source dependencies. No Konami ROM, extracted cartridge graphics/audio or private asset bundle is included. Supply a supported cartridge on first launch; extraction runs locally without openMSX.

Windows x64, Linux x64, macOS Intel and Apple Silicon builds are provided. Only Windows runtime behavior has been checked locally; the other platforms are built by GitHub Actions.
